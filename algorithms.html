Enhancement Summary

This enhancement focused on improving the Android Inventory Management Application through better searching, sorting, and inventory prioritization features.

  • Implemented low-stock prioritization
  • Improved information retrieval and organization

Narrative

Artifact Description

The artifact I selected for this enhancement is my Android Inventory Management Application that I originally created in CS 360. The application allows users to manage inventory records through a mobile interface connected to a SQLite database. For this milestone, I focused on improving how inventory information is organized, searched, and prioritized through the use of algorithms and data structures.

Justification for Inclusion

I selected this artifact because it provided a strong opportunity to implement practical algorithms and data structures in a real-world application. While the original version allowed users to add and manage inventory records, it lacked advanced methods for finding, organizing, and prioritizing information. These enhancements demonstrate how data structures and algorithms can improve both usability and efficiency.

Enhancements Implemented

The first enhancement was the addition of a search feature. Users can now search inventory items by part number, item name, or description. This functionality uses an ArrayList and a filtering algorithm that performs a linear search through inventory records to locate matching results.

The second enhancement was the addition of sorting functionality. Users can sort inventory records by part number, description, quantity, or newest items first. This feature uses comparator-based sorting through Java collections to organize information according to user needs.

The third enhancement was the creation of a low-stock reporting feature. This report uses a PriorityQueue to automatically prioritize inventory items based on quantity levels, ensuring that the lowest inventory items appear first.

Algorithms and Data Structures Used

  • ArrayList for inventory storage and retrieval
  • Linear Search with O(n) complexity
  • Comparator-Based Sorting with O(n log n) complexity
  • PriorityQueue for low-stock prioritization

Course Outcome Alignment

These enhancements demonstrate the use of algorithmic principles and data structures to solve practical inventory management problems. The application now provides users with faster access to information and improved organization of inventory records. The use of searching, sorting, and prioritization techniques aligns directly with the Computer Science program outcome focused on designing and evaluating computing solutions using algorithmic principles.

Challenges and Testing

One challenge I faced was ensuring that search results remained accurate after inventory records were added, edited, or deleted. I also needed to verify that sorting continued to work correctly alongside the search functionality. Testing included searching for inventory records, sorting data using different methods, updating inventory quantities, and generating low-stock reports with different thresholds.

I verified that inventory records appeared correctly in search results, that sorting organized data properly, and that the PriorityQueue consistently prioritized the lowest inventory quantities first.

This enhancement helped me better understand how algorithms and data structures affect software usability and performance. By implementing search, sorting, and prioritization features, I was able to transform the application into a more useful inventory management solution. This project reinforced the importance of selecting appropriate data structures and algorithms to solve real-world problems efficiently.
