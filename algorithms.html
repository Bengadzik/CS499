Narrative

Artifact Description

The artifact I selected for this enhancement is my Android Inventory Management Application that I originally created in CS 360. For this milestone, I focused on algorithms and data structures by improving how inventory data is searched, sorted, and prioritized.

Justification for Inclusion

I selected this artifact because it provided a strong opportunity to implement practical algorithms and data structures within an existing application. The original application contained inventory management features, but lacked advanced methods for organizing and retrieving information efficiently.

Enhancements Implemented

The first enhancement was a search feature that allows users to locate inventory items using part numbers, item names, or descriptions. This feature uses an ArrayList and a filtering algorithm that performs a linear search through inventory records.

The second enhancement was inventory sorting. Users can now sort inventory by part number, description, quantity, or newest items first. This functionality uses comparator-based sorting provided through Java collections.

The third enhancement was a low-stock priority report that uses a PriorityQueue to automatically prioritize inventory items based on available quantity.

Algorithms and Data Structures Used

  • ArrayList for inventory storage and searching
  • Linear Search with O(n) complexity
  • Comparator-Based Sorting with O(n log n) complexity
  • PriorityQueue for low-stock prioritization

Course Outcome Alignment

These enhancements demonstrate the use of algorithmic principles and data structures to solve practical inventory management problems. The application now processes information more effectively and helps users make decisions using prioritized and organized data.

Challenges and Testing

A challenge I faced was ensuring that search results continued working correctly after inventory updates, edits, and deletions. Sorting functionality also needed to remain compatible with filtered search results.

Testing included searching for inventory records, sorting using different methods, updating quantities, and generating low-stock reports with different thresholds to verify accurate results.

Reflection

This enhancement helped me better understand how algorithms and data structures impact software usability. The final result is a more capable inventory application that demonstrates practical applications of searching, sorting, and prioritization techniques.
