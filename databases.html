Narrative

Artifact Description

The artifact I selected for this enhancement is my Android Inventory Application originally created in CS 360. The application stores inventory information using a local SQLite database and allows users to manage inventory through a mobile interface.

Justification for Inclusion

I selected this artifact because database functionality is a major component of inventory management systems. The project provided an excellent opportunity to demonstrate database design, reporting, and historical data tracking.

Enhancement Overview

For this enhancement, I expanded the application's database functionality by adding inventory usage tracking and reporting features.

I created a new usage_history table that stores item information, quantity used, ticket numbers, and transaction dates whenever inventory is picked. This allows historical inventory activity to be retained instead of only storing current quantities.

I also implemented a Usage Report feature and a Top Used Parts Report that retrieve and summarize inventory activity using stored database records.

Database Design and Reporting

The usage_history table creates a relationship between current inventory records and historical transactions. This design supports long-term reporting while maintaining current inventory quantities.

The reporting features use aggregate database queries such as COUNT and SUM to calculate usage statistics and identify frequently used inventory items. These reports transform raw data into meaningful business information.

Course Outcome Alignment

This enhancement demonstrates database design, data organization, reporting, and decision-support functionality. It also supports the development of computing solutions that provide value through effective data management and analysis.

Challenges and Testing

One challenge was ensuring inventory quantities and usage history remained synchronized. Careful planning and testing were required to ensure transactions updated both inventory records and historical data correctly.

Testing included verifying quantity updates, history record creation, summary statistics, and Top Used Parts reporting functionality.

Reflection

This enhancement helped me better understand how databases support real-world applications. The project now stores historical inventory activity, generates reports, summarizes usage information, and provides a more complete inventory management solution than the original version.
