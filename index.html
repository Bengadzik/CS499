Professional Self-Assessment

As I complete my Bachelor of Science in Computer Science, I can see how much I have learned throughout the program and how much I have grown both technically and professionally. The courses I completed helped me build a strong foundation in software development, databases, algorithms, security, and problem solving. Creating this ePortfolio gave me an opportunity to look back at the work I completed throughout the program and see how my skills have improved over time. It also allowed me to demonstrate those skills through the enhancement of an existing project instead of simply creating something new. One of the biggest things I learned throughout the program was the importance of collaboration and communication. While computer science often focuses on technical skills, successful projects also require working with other people. In my professional career as an Operations Support Manager, I regularly work with technicians, developers, project managers, and customers to solve problems and support business operations. Throughout my coursework, I also learned how important it is to communicate technical information clearly to different audiences. This was demonstrated through project documentation, presentations, written reports, and the code review completed for this capstone project. Being able to explain technical concepts in a way that others can understand is a skill that will continue to be valuable throughout my career. The Computer Science program also strengthened my understanding of software design and engineering principles. Throughout my courses, I learned how to design applications, organize code, test functionality, and improve existing systems. My software engineering enhancement focused on expanding an Android Inventory Management Application that I originally developed in CS 360. I improved the application by adding part numbers, descriptions, inventory picking functionality, usage tracking, reporting capabilities, and additional validation. These enhancements helped transform a basic inventory application into a more realistic business solution while demonstrating software design, planning, testing, and maintenance skills. Another important area of growth was learning how algorithms and data structures impact software performance and usability. Throughout the program, I worked with arrays, lists, queues, sorting algorithms, and searching techniques. For my algorithms and data structures enhancement, I implemented inventory searching, sorting, and low-stock prioritization features. These enhancements allowed users to organize and locate information more efficiently while demonstrating practical uses of ArrayLists, sorting algorithms, and PriorityQueue data structures. This project helped reinforce the importance of selecting appropriate data structures to solve problems effectively. Database design and development was another major area of learning throughout the Computer Science program. I learned how databases store, organize, retrieve, and analyze information while supporting real-world business operations. For my database enhancement, I expanded the Inventory Management Application by creating a usage history table, inventory reporting features, summary statistics, and a Top Used Parts report. These enhancements demonstrated database design, data management, aggregate queries, and reporting functionality. Working on these features helped me better understand how databases provide value by turning stored data into useful information that supports decision making. Security was also an important topic throughout the program. I learned that security must be considered throughout the entire software development process rather than being treated as an afterthought. Through coursework and project development, I gained experience with user authentication, validation, secure coding practices, and protecting application data. Within my Inventory Management Application, I implemented validation controls to help ensure inventory data remains accurate and to prevent invalid input from affecting application functionality. These experiences helped me develop a stronger security mindset and a better understanding of how secure design contributes to reliable software solutions. The artifacts included in this ePortfolio work together to demonstrate my growth throughout the Computer Science program. The code review provides an overview of the original application and identifies areas for improvement. The software engineering enhancement demonstrates application design and feature development. The algorithms and data structures enhancement demonstrates problem solving through searching, sorting, and prioritization techniques. The database enhancement demonstrates database design, reporting, and data analysis capabilities. Together, these artifacts show how a single application can be enhanced through multiple areas of computer science to become a more complete and valuable solution. The Computer Science program has helped me develop both technical and professional skills that I will continue to use throughout my career. It strengthened my ability to solve problems, communicate effectively, work with technology, and approach software development from multiple perspectives. Completing this ePortfolio allowed me to showcase those skills while reflecting on the progress I have made throughout the program. I am proud of what I have accomplished and look forward to applying these skills in future professional opportunities.
